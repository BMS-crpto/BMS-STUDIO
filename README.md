# MyCut Pro — Android video editor starter (v0.2)

Independent Android project source. Not affiliated with CapCut and does not contain CapCut code/assets or premium unlocks.

## Features in this build
- Android video picker and local video preview (Media3 ExoPlayer)
- Basic trim range controls (choose start at playhead; adjust end slider; reset)
- Original, Mono, Sepia, Warm, and Cool color presets
- Media3 Transformer export to MP4 and copy into Movies/MyCutPro
- Android dark UI

## Build on Android
1. Download and extract this ZIP.
2. Open the `MyCutPro` folder in AndroidIDE or Android Studio.
3. Let Gradle sync and download dependencies (internet required).
4. Build/run the app module.

## Notes
This is an initial MVP, not a complete professional editor. Current trim controls set the start and end of an export; no multitrack timeline, audio mixing, transitions, captions, keyframes, 4K options, or advanced GPU effects yet. AndroidIDE compatibility depends on the installed JDK/Gradle/SDK versions.
